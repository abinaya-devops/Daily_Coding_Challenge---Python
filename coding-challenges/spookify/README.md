## SpOoKy~CaSe – Python Coding Challenge

### Problem

Convert a variable name into spooky case by replacing underscores and hyphens with tildes and alternating uppercase and lowercase letters.

Example

Input: "hello_world"

Output: "HeLlO~wOrLd"

### Concepts Practiced

- String replacement
- Uppercase and lowercase conversion
- For loops and conditions
- Modulo operator
- Continue statement
- String concatenation
