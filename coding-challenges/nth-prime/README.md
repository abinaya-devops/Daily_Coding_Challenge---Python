## Nth Prime – Python Coding Challenge

### Problem

Given a positive integer "n", return the nth prime number.

Examples

- "nth_prime(5)" → "11"
- "nth_prime(10)" → "29"
- "nth_prime(16)" → "53"

### Concepts Practiced

- Prime number checking
- Functions
- "for" and "while" loops
- Modulo operator ("%")
- Function calls and return values
- Counters and candidate variables

### Solution

The "is_prime()" helper function checks whether a candidate number is prime. The "nth_prime()" function counts prime numbers until it reaches the requested position.
