# Email Sorter — FreeCodeCamp Python Challenge

## Problem

Sort email addresses by domain name first and username second, using case-insensitive comparisons while preserving the original email address casing.

## Concepts Learned

- "split("@")" — separate username and domain
- "lower()" — case-insensitive sorting
- Tuples — sort by domain first, then username
- "sorted()" with "key" — custom sorting logic
- Preserve original email addresses in the output

## Learning Reflection

I solved this challenge step by step and practised identifying the username and domain, building a sorting key, and understanding how Python's "sorted()" function uses the key to order email addresses.
