Day 12 – Character Limit

Challenge

Determine whether a social media post fits within the character limits:

- ""short post"" if the post contains 40 characters or fewer.
- ""long post"" if the post contains more than 40 and up to 80 characters.
- ""invalid post"" if the post contains more than 80 characters.

Concepts Learned

- "len()" function
- "if", "elif", and "else" conditions
- Logical operator ("and")
- Comparison operators ("<", ">", "<=")
- "return" statement
- String length calculation
- Boundary value checking

What I Learned

- How to calculate the length of a string using "len()".
- How to check multiple conditions using "if" and "elif".
- How the "and" operator works when checking two conditions.
- How to use "else" to handle remaining cases.
- Why boundary values such as 40, 41, 80, and 81 are important.
- How to return different results based on string length.
