Day 04 – Python Learning: SpOoKy~CaSe

Challenge

Convert a variable name into spooky case:

- Replace underscores ("_") and hyphens ("-") with tildes ("~").
- Capitalize the first letter and every alternate letter.
- Ignore tildes when counting letters.
- Convert all other letters to lowercase.

Concepts Learned

- String "replace()"
- "upper()" and "lower()"
- "for" loops
- "if/else" conditions
- Modulo operator ("%")
- "continue" statement
- String concatenation
- Tracking characters with a counter variable

What I Learned

- How to replace multiple characters in a string.
- How to alternate uppercase and lowercase letters.
- How to skip special characters while counting letters.
- How "continue" skips the remaining statements in the current loop iteration.
