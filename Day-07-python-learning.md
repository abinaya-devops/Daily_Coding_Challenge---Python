Day 07 – Word Counter

Challenge

Word Counter – freeCodeCamp Daily Coding Challenge

Problem Description

Given a sentence string, return the total number of words in it.

Words are sequences of non-space characters separated by a single space.

Concepts Learned

- "split()" – Splits a sentence into a list of words.
- "len()" – Counts the number of items in a list.
- "return" – Sends the result back from a function.
- "print()" – Displays the result in the terminal.
- Python functions and variables.

Solution Approach

1. Accept the sentence as a function parameter.
2. Use "split()" to separate the sentence into words.
3. Use "len()" to count the words.
4. Return the total count.

Example

Input:

"I love Python"

Output:

3
